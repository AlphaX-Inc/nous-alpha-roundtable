SCREEN 4 · ROUNDTABLE
Each of the 11 avatars is connected to a specific Claude Code subagent. On screen mount, the page calls /api/roundtable on the Nous backend (override via window.NOUS_BACKEND_URL). In stub mode the backend serves canonical demo data; in live mode (ANTHROPIC_API_KEY set on the backend host) each persona invokes its mapped subagent via the Claude Agent SDK and Opus 4.7.
